## 四、三套体型的本质区别（最容易踩的坑）

| | 2.5D 饼干体 | **努努体（custom-body）** | 公开图纸（nunu-public） |
|---|---|---|---|
| 图纸来源 | 模板自带 2 张带 3D 网格的头脸 | `NunuBody.generate()` 现生成 17 片 | pattern-data 静态 15 片 |
| 设计台改体型 | ✅ 白坯随便拉扯 | ❌ **禁止**（会拆散图纸） | ❌ 禁止 |
| 彩绘落点 | 映射到网格头脸（mapped 分支） | **仿射映射回图纸原片**（pattern 分支） | 同努努体 |
| 新发片/衣服 | 重长纸样 | **追加**到图纸后面 | 同 |

判定逻辑在 `nunu-design.js` 的 `template()`：
- `mapped` = 有 2 张名字 `头部*` 且带 mesh 的片 → 2.5D 走网格映射
- `pattern` = 有 isFace 片 + bodyFront 片 → **整张图纸型**：`mapOnto()` 把设计台对象的笔迹/贴图按仿射反解（横向中心对中心、纵向顶对顶、背片盒内镜像）映射回图纸原片，新对象走 queue 追加
- 都不是 → 清空重长（只该发生在导入的陌生图纸上）

**历史教训**：2026-10-30 之前 pattern 型也走清空重长，努努体上涂一笔 17 片毁成 4 片（老板当场抓住）。现在有 `tests/nunu-pattern-map.test.cjs` 5 项锁死这个行为。

改体型的锁：`app.js` mount 时传 `shapeLocked()`（按当前模板动态判断），设计台在拖手柄/拖移动把手/起笔落在图纸原片内三处拒绝并解释；起笔在空白 = 开新片草稿，照常放行。

## 五、设计台核心机制（nunu-design.js）

- **白坯**：`initial(tpl)` 按当前模板长出 face+body 两对象；努努体用图纸的 脸片（前）+身体·前 缩放摆放。
- **涂形状（smear，默认）**：改体型下按住涂 → 笔迹进离屏 mask（`smearInto`）→ 点「✓ 就这一片」→ `polyFromMask()`（outerContours 取最大连通块）成片。**一笔围成一圈（转角≥240°+不自交）松手自动成片**（`commitClosed`）。成不了片**草稿保留**，绝不整笔作废。
- **慢慢描（line）**：画一段松一次手，段自动接上；单段必须用开链 `S.dp` 简化（`simplifyLoop` 是给闭合环的，会把封口线上的末点当废点删掉——踩过）。
- **发片**：新片长在画的地方（**不再自动吸附发际线**，吸附要手动点「↥ 贴回发际线」）；缝（sewn，沿发际线缝）/贴（glued，从发际线往下贴）两种工艺；有厚度（3D thick=9，多层 z 逐层 +0.024）。
- **透明底发片**：传 PNG 按 alpha 抠形（白底兜底按白抠），一坨颜色一片，透明处留空窗。
- **确认条**（改体型的 ✓/✕ 和草稿条）**fixed 在视口底部**——曾因在视口外（y=986>屏高900）导致"点了没反应"。
- **大画布**：⛶ 按钮 收起全部面板（`ds.dsBig`），Esc 退出。
- **抓手**：`tool='hand'` 时 2D 拖平移；同时 `body.ds-hand` 让 3D 左键也能转（app.js 里 `document.body.classList.contains('ds-hand')`）。

## 六、数据流与存档

- 存档：localStorage `nunu-v4`，`tplData[模板id].design` 存设计台数据、`.hairstyle` 等并存；作品列表 `projects`。
- `buildDoc()`：`designed = design && !isBlankDesign(design)` → 设计台长纸样，否则用模板原纸样。
- `isBlankDesign()`：无 `edited` 标记 + 对象≤2 + 无笔迹 → 白坯不落库、不盖原图纸（救过"努努刷新只剩4片"的命）。
- `booting` 闸：开页面期间 change/live 回调不写库。

## 十二、分页画法（v55–56，整张图纸体型：努努体 / 公开图纸）

春子的话：努努画脸和 2.5D 不一样——面部一张平面、身体一张平面，各分正/背；发片单独一页；不能改体型所以没有改体型按钮；发片能自己挪。

- `shapeLocked()` 为真时 `pageMode()` 开启，`visibleIn(o)` 决定每页显示谁：面部·正面=脸片；面部·背面=后脑左右两片（对象 `headL/headR`，带 `piece` 字段，单面，笔迹存 `front`，从背后看左右互换摆放）；身体·正/背=身体·前/后；发片、衣服页整只娃都在。
- `BASE_IDS = face/body/headL/headR` 是图纸原片：不能改形、不能放大缩小、不能删。老存档靠 `withBackHead()` 补上后脑两片。
- `template()` pattern 分支现在映射：脸片、身体·前（有画才映）、身体·后、后脑两片（有画才映，免得盖掉头发底色）。以前漏了身体·前，所以身体上画的东西 3D 不出现、撤销看着像没动。
- 「改体型」按钮对整张图纸体型只在发片/衣服页出现，改名「挪发片」：按住发片里面直接拖就是挪位置。
- 📏 定位线（脸窗、眼、嘴、眼线）只在面部·正面页。涂形状的笔改成深橙色。大画布改成真全屏（盖住顶栏底栏，并请求浏览器全屏，Esc 退出）。
- `isBlankDesign` 的对象数上限从 2 放宽到 4（整张图纸体型的白坯带后脑两片）。
- 未做：耳朵、手臂、下巴、头顶发的彩绘页；后脑两片的「看纸样」视图映射。
- v57：画布吃满整个舞台（`VW/VH` 跟着舞台大小，ResizeObserver 监听），不再是 4:5 的窄板；世界坐标仍是 400×500，但摆放 / 涂形状的范围往四周各扩 160（`PADX/PADY`，涂形状的累积画布 `MW×MH` 带偏移），发片可以翘出头外、摆到旁边。`nunu-shape-edit` 里贴边测试的边界随之改成 -160…560 / -160…660。
