## 三、根因（这部分值得看一眼）

### 1. 画笔「到处乱飞」——真凶是画布矩形在漂移

每一小段鼠标移动都会触发一次全量刷新，连带重排下方 dock 的 DOM；而画布的 CSS 宽写成了 `min(100%, 54.4vh)`，DOM 一重排（比如滚动条出现/消失）画布的实际宽度就变。代码每帧都重新读 `getBoundingClientRect()`，**同一笔画里前后采样点的换算基准不一样**，笔迹就被撕开。

三处修复：
- 按下鼠标那一刻**锁住画布矩形**，整笔用完再释放
- 实时刷新收敛到一帧一次（`requestAnimationFrame`），并且只刷改动的那一片
- CSS 改成容器锁 `aspect-ratio: 4/5`，和画布内部像素比例一致，不再跟着 vh 抖

### 2. 「自己画头乱飞」——`symmetricOutline` 会产出废形状

它对输入轮廓做「留一半再镜像」。当画的多数点堆在对称轴同一侧时，会生成带重复顶点的退化多边形，被自交检查判失败，**用户这一笔就被静默丢掉了**——看起来就像形状突然没了/乱了。

重写了这个函数：改用半平面裁剪取主半侧，去掉重复顶点，做完还校验一次。并且加了一条原则：

> **对称做不出来时，保留你画的形状并如实说明，绝不默默丢笔。**

### 3. 过程中的两次自我纠正（诚实记录）

- 我一开始怀疑「缩放脸之后笔迹会跟裁片脱钩」，实测下来偏差只有 **0.68px**（约 0.17%），肉眼不可见；而修它的代价是 3D 模型的缩放线性度从严格变成 0.6% 误差。**不划算，我把那个改动撤回了。**
- 另一个是我自己写歪的：原本提示写「形状照你画的留下了」，可实际整笔被还原，**文案没兑现**。现在改成真的保留再说实话。

### 4. 顺手抓到的两个 bug

- **错误提示一闪就没**：`sync()` 的默认说明会把刚设置的报错文案覆盖掉。改成分优先级的通知队列，报错优先显示。
- **`adding` 时仍去抢选中**：正准备新增一片时，落点若压在已有部件上，会被判成「改那一片」——这正是「加了发片却加不上」的来源。

## 四、「断成一个个点」的根因

三层叠加，每一条都可能是你遇到的「断掉」：

1. **浏览器把中间点合并掉了。** 每画一帧都要刷新右边的 3D，帧一慢，浏览器就把一串 pointermove 合并成一个事件，程序只拿到起点和几个稀疏的点 —— 笔迹自然就稀稀拉拉只剩一个个点。修法：用 `getCoalescedEvents()` 把被合并掉的中间点全部取回来。
2. **指针跑出画布就收不到事件了。** 以前 move / up 只挂在 canvas 上，还要靠 setPointerCapture 兜底；捕获一失效（比如指针出了画布、上面压了别的元素），后面就收不到了。修法：按下之后同时挂到 window 的捕获阶段，收得到就丢不掉。
3. **浏览器中途抢走指针时，以前会把已经画好的整笔抹掉。** 修法：取消时保留已经落下的部分（不想要就撤销），不再整笔清零。

这三条都有对应的自动化验收（`tests/nunu-image.test.cjs` 第 6 项、第 7 项，`tests/nunu-interaction.test.cjs` 第 5 项）。

# 第三批（2026-10-29 18:04 提的）：发片的工艺

## 一、你说的，我先去查证了

按你说的「发片尤其是后发片应该是从连接处、就是发际线出来的，是缝出来的；前刘海发片是黏贴的，是从发际线往下黏贴或者直接贴上去和搬砖一样」，我去搜了小红书 / B 站 / 森空岛 / 微博上的努努与棉花娃娃教程。三条独立来源口径一致：

- 「**贴上**刘海发片」→「藏针法**缝合**后大发片」→「后大发片**缝合到耳朵位置**」
- 「前额的发片…为了**发际线对齐**，沿着面皮的缝合线缝合」
- 「以**发际线和皮肤交界处**为中点」
- 「沿着分区线，**从发际线开始，一层压一层地粘贴**」（就是你说的搬砖式）

**结论：你说的完全对。** 后发片是沿发际线缝出来的；刘海是在发际线涂胶往下贴、一层压一层铺上去的。而工作台原来把**所有**发片都写成「正反两片背对背粘合」——后发片也粘，这不符合工艺。

## 二、改完后是什么样

| 你提的 | 现在的情况 |

| 后发片不是凭空冒出来，是从发际线缝出来的 | ✅ 新建发片**自动把根部贴到发际线上**（实测偏差 0.0000），纸样上标出紫色的「发根缝」标记，安装说明写「根部对准头部发际线，沿发际线加固缝一圈」 |
| 前刘海是黏贴的，从发际线往下贴 / 整片贴 | ✅ 盖住额头的发片默认判成「贴」，纸样上标橙色「发根贴」，安装说明写「在发际线涂布料胶，从发际线往下压着贴；想厚就一层压一层往上叠（像铺瓦），每层都从发际线起」 |
| （隐含）怎么区分缝还是贴 | ✅ 选中发片时弹出一行工艺切换：「🧵 缝在发际线 / 🩹 贴上去」，自动判定只是一个默认值，**真正的工艺你说了算**。切到「缝」会立刻把根部吸回发际线 |

装配画布上画出了一条淡蓝色虚线「发际线」（面皮的上缘弧），每片发片的根部用紫虚线（缝）/橙点线（贴）标出来，一眼分得清这片是缝的还是粘的。旁边还多了一个「↥ 贴回发际线」按钮，挪歪了一键归位。

## 三、过程中抓到的真 bug（都有测试盯着）

1. **根部取错了**：`rootOf` 原本找的是「最靠上的那个**点**」，对四边形发片会挑到某个角，算出一条斜跨整个顶部的边，吸附后直接把发片顶出画布。改成找「最靠上的那条**边**」。
2. **吸附会把发片弄丢**：根部挪到发际线时如果整片会跑出画布上边界，原来照样挪。现在越界就**拒绝挪动**，宁可留在原地。

## 六、还没做 / 可能存在的问题

- **自动判定是弱判据**。装配画布是正视图，脸占了中央一大块，前后发片都落在脸的范围内，2D 里根本分不出前后 —— 我只能靠「主体垂到脸部中线以下 = 刘海，停在头顶 = 后发片」猜个默认值。**遇到画得很垂的长发发片可能判错**（这类发片工艺上是缝的，但质心低）。判错了你点一下工艺切换就行，这个选择会被记住。
- **「发际线」是面皮的上缘弧**（脸轮廓上部 34% 以内那条弧）。教程里发际线也就是面皮边缘，这个对应是准的；但如果你画的脸形状扁、或者画到了别的层，这条线的位置会跟着变。
- **3D 上发片还是一片平面**贴在头部前/后，没有真正贴住球面弯曲。2.5D 装配图把根部对准了发际线、纸样也标了缝合位置，但 3D 预览的「贴合感」只到「缝的发片比贴的发片更往里收」这一步。要真正的球面贴合得重写 3D 装配，那是另一个量级的改动。
- 老规矩：**没 push 上线，dist 没重新构建**，你先过目。
