# 娃厂 · 论坛 · 认证 · 赞助 说明书

> 页面里「娃厂」和「论坛」右上角的「📖 说明书」是同一份内容。

## 娃厂榜
- 红榜 = 综合评分高的，黑榜 = 低的。新上传、还没人评的娃厂不上榜，在「全部娃厂」里找。
- 点进娃厂：评价、相关 Repo、相关避雷都在里面；已入驻的能联系客服。
- 「＋ 上传娃厂」：名字 2–16 字（不重名）、标签最多 3 个、一句话介绍。名字和简介里不放网址 / 联系方式；新账号一天只能传 1 家。

## 打分、评论、帖子、点赞的规矩
| | 规矩 |
|---|---|
| 打分 | 每天最多 5 家，同一家一天一次，不能给自己上传的娃厂打分 |
| 打分（权重低的账号） | 同一天不能「一家 ≥9 分、另一家 ≤3 分」；不能把大家公认的好厂打极低分、把公认的差厂打极高分。权重高放宽 |
| 打分（算分） | 按账号权重加权；一家一天涌进来很多非高权重账号的极端分，超出的不计分 |
| 评论 | 2–100 字；一天 5 条（新账号 3 条）；同一家一天一条；不能评自己上传的厂；不放网址 / 联系方式 |
| 帖子 | 标题 4–30 字、正文 10–500 字；一天 5 帖（新账号 2 帖）；不放网址 / 联系方式；3 人举报先折叠 |
| 点赞 | 一天 10 个（新账号 5 个）；不能赞自己的；同一帖只能赞一次 |

**账号权重**：用得越久、做的娃娃越多、评得越多，权重越高（低 / 中 / 高）。新账号的票更轻、限制更严。

| 🌸 棉花娃娃宣传区 | 展示你自己的娃 | 所有人（不能带价格 / 接单 / 开团等买卖信息） |
| 🧵 手作娘接单 | 个人手作娘接单 | 所有人，**不用认证**，但必须走第三方平台（见下） |

- 娃厂业务的分类：接单 / 开单、活动 / 优惠、新品上线、招人 / 合作、其他。
- **娃厂打广告、做生意需要入驻**：没入驻的在宣传区 / 体型图 / 经验里带价格、接单、开团等买卖信息会被拒。
- **不得发布敏感话题**（政治、色情、赌博、毒品、暴力、诈骗等）；发联系方式 / 网址引流会被拒；3 个人举报先折叠。（敏感词过滤只是最基本的一层，联网后要加人工审核。）
- 每天最多发 5 帖（新账号 2 帖）；点赞每天 10 个（新账号 5 个），不能赞自己的。
- **娃厂不能给自己评分、刷分**：自己上传的娃厂不能打分、不能评论；不能给自己的娃厂发 Repo / 避雷；不能赞自己的帖子。想宣传自己，用「娃厂业务」区（要入驻）。

## 手作娘接单区
- **不用认证**，但**必须走闲鱼 / 淘宝 / 天猫 / 拼多多 / 京东这类有交易保障的第三方平台下单**：发帖要选平台、写你在平台上的店铺名或商品标题（让别人搜到你）。
- **不能提私下转账、扫码、不走平台、加好友私聊**，会被拒。交易纠纷由平台处理，我们不是中介、不担保。

## 社区公约
大家都是**为爱发电**，不是客服。教程、经验、帖子的作者没有义务回复你：请不要反复私信、催更；**不回你是正常的**。请保持礼貌，先自己多探索（搜帖子、看说明书、动手试试），再提问，提问时写清楚你试过什么。这段话会显示在论坛和娃厂页顶上的公告里。

## 账号、备份（重要）
- **因为没钱租服务器**，账号、作品、评分、帖子、私信暂时都只存在**你自己的浏览器**里：清缓存、换浏览器、换设备数据就没了，忘记密码也没法找回。
- 请在「我的」页**及时「⬇ 下载备份」**（超过 7 天没备份会标红提醒），换设备时「⬆ 导入备份」。
- 注册 / 登录用用户名 + 密码（8 位以上、要有字母和数字）；密码只存加盐后的哈希，不存明文。登录只是区分这台浏览器上的账号，**防不了别人用你的电脑**。
- 没登录只能看，评分、评论、发帖、点赞、私信、上传娃厂都要先登录。

## 私信（短期交流过渡）
- 入口：「我的」页的「✉️ 私信」，或论坛帖子旁的「私信」按钮。
- **我们不是中介平台，不担保任何交易，小心上单被骗**：不要提前转大额定金；不要私下转账给陌生人；不要扫陌生二维码、点陌生链接；想联系娃厂优先用「✔ 已入驻」的官方客服；聊天记录、付款凭证、实拍图都留好。出了问题要自己和对方处理，平台不负责后续对接。每个私信窗口顶上都写着这段提醒。
- 现在是单机版：消息只存在你这台浏览器里，**对方暂时收不到**，联网后才能真正收发；私信只保留 7 天；每天最多 10 条（新账号 3 条），不能发敏感话题。

## 娃厂入驻（付费）
- 点进一家娃厂，里面是：**评价**（打分 + 评论区）、**相关 Repo**、**相关避雷**，还能直接在里面「发 Repo / 发避雷」。
- 已入驻的娃厂带「✔ 已入驻」，点进去能看到**官方客服**怎么联系；没入驻的没有客服入口，只能看大家的评价、Repo、避雷。
- 娃厂想入驻：打赏站长后，到「我的」页看站长微信，把**赞助码 + 娃厂名字 + 客服联系方式**发过去，站长确认后加上。
- **平台只提供入口，不负责后续对接**：下单、付款、售后、纠纷都由玩家和娃厂自己处理。入驻只代表有官方客服入口，不代表质量，也不影响评分和榜单排序。

### 站长（管理员）怎么管
1. **生成管理员口令**：登录窗口底下「我是站长：生成管理员口令」，输入站长用户名和密码（要又长又复杂），会生成一段 `"admin": {...}`（只含盐和哈希）。
2. 把它贴进 `public/games/nunu-studio/sponsors.json`，重新上线。
3. 用**同样的用户名密码**注册、再登录一次，「我的」页就多出「🛠 管理台」（别人看不见）。
4. 管理台里可以：加 / 删**入驻娃厂**（和客服）、**感谢榜**、**公告**、站长微信。改的是**草稿**，存在本机、你自己的浏览器里立刻生效；点「⬇ 导出 sponsors.json」，替换项目里的文件再上线，**所有人才能看到**。

`sponsors.json` 长这样：
```json
{
  "ownerWechat": "你的微信号",
  "admin": { "name": "站长用户名", "salt": "…", "hash": "…" },
  "joined": [ { "name": "云朵朵工坊", "service": "客服微信 xxxx" }, "栗子壳玩偶厂" ],
  "thanks": [ { "name": "某某", "note": "谢谢", "date": "2026-10" } ],
  "notices": [ { "title": "📢 维护通知", "body": "今晚停机", "date": "2026-10-30" } ]
}
```
- 感谢榜**经本人同意再写**。这个文件不在构建产物里，上线时要一起传。
- **管理员是前端的，只决定你自己的浏览器里看不看得见管理台**；真正的权限（比如能不能删别人的帖子、改别人的数据）要等有服务器。哈希在公开文件里，所以密码要够长够复杂。

## 数据在哪
现在评分、评论、帖子都存在各自的浏览器里，别人看不到，清掉浏览器数据就没了；示例厂和示例帖是虚构的。上面的规矩只能防正常使用里的顺手刷分；**联网同步上线时，同一份规矩（`nunu-factory.js`）要搬到服务器上跑，账号权重以服务器为准。**
